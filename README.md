# Lumo · download

Corsa a ritmo in un mondo a cubetti: dieci mondi, dieci colonne sonore originali, una vela diversa per ogni mondo e una classifica online.

Scarica l'ultima versione dalla pagina [Releases](https://github.com/biagiobartoli/lumo-download/releases/latest):

- **Mac** (Apple Silicon e Intel, macOS 11+): `Lumo-mac.zip`. Al primo avvio: clic destro sull'app → Apri.
- **Windows** (10 e 11, 64 bit): `Lumo-windows.zip`. Se compare "Windows ha protetto il PC": Ulteriori informazioni → Esegui comunque.

iPhone, iPad e Android: in arrivo.
